# A Study in Pixels

A small experimental pygame project that transforms images into interactive pixel art with animated falling particles.

The program allows user to:

  - Upload their own image
  - Apply a pixel effect that can be turned on and off
  - Generate a leaf falling particle system sampled from the image colors for cohesion
  - Resiszing display window
  - Export end result as a GIF file

## Features

- File selection using tkinter
- Pixel effect through multiple resizing actions
- Falling leaves with sway motion
- Particle color sampling
- Particle shadows for depth
- GIF recording

## Libraries used

- math
- random
- os
- pygame
- Pillow
- tkinter

## Inspiration

The goal is to experiment with image manipulation, ambiance features, light animation, and color driven features using pygame.
